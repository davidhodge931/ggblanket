# Changelog

## ggblanket 30.0.0

CRAN release: 2026-10-29

- Changed border argument names to polygon.
- Removed `set_blanket`, and provided `set_*` functions for the various
  options.
- Plus more!

## ggblanket 21.0.0

CRAN release: 2026-07-07

- Renamed `facet_wrap` to `facet`.
- Support for named palettes (i.e. manual scales).
- Changed `coord_clip` default to `"on"`.
- Updated `refine` method.
- Removed `focus` argument.
- Added `theme` argument.
- Fixed `facet_space` and `facet_labeller` argument.
- Fixed `colour_name = NULL` bug.

## ggblanket 20.0.0

CRAN release: 2026-05-07

- Complete rethink and rewrite of the package.
